# Welcome to Physical AI & Humanoid Robotics Book

This comprehensive guide bridges the gap between digital AI and embodied intelligence in the physical world. You'll learn how to create intelligent robotic systems that can perceive, think, and act in real environments.

[Get Started](#what-youll-learn)

## What You'll Learn

- **Module 1**: [ROS 2 Fundamentals](/module-1-ros2) - The nervous system of robots
- **Module 2**: [Simulation Environments](/module-2-gazebo-unity) - Gazebo and Unity
- **Module 3**: [AI Perception & Navigation](/module-3-nvidia-isaac) - Making robots aware
- **Module 4**: [Humanoid Robotics Capstone](/module-4-vla-humanoid) - Bringing it all together

## Target Audience

This book is designed for:

- Beginner to intermediate students in AI, robotics, and computer science  
- Learners with basic Python knowledge exploring Physical AI and humanoid robotics  
- Institutes or educators deploying modern robotics curriculum  

## Learning Approach

Each chapter follows a consistent structure:

- **Explanation:** Clear concepts in simple English  
- **Example:** Practical scenarios and applications  
- **Diagram:** Visual representations with alt-text  
- **Code:** Runnable examples with verification steps  
- **Practice Task:** Hands-on exercises to reinforce learning  

## How to Use This Book

Follow the 13-week learning plan:

- **Weeks 1-2:** Introduction to Physical AI concepts  
- **Weeks 3-5:** ROS 2 fundamentals  
- **Weeks 6-7:** Gazebo simulation  
- **Weeks 8-10:** NVIDIA Isaac platform  
- **Weeks 11-12:** Humanoid robotics  
- **Week 13:** Conversational robotics and capstone project  

## Capstone Project

The book culminates in a capstone project where you'll build a simulated humanoid robot that follows the **Voice → Plan → Navigate → Perceive → Manipulate** workflow, integrating all concepts learned throughout the modules.

## Accessibility

All diagrams include alt-text descriptions, and the site follows **WCAG 2.1 AA standards** to ensure an inclusive learning experience.
