# 12-Chapter Physical AI Book using Docusaurus (ROS 2, Gazebo, NVIDIA Isaac, VLA) Constitution

## Core Principles

### I. Beginner-friendly clarity
Simple English and easy explanations suitable for students new to physical AI concepts. Writing style must be accessible to beginners with minimal technical background.

### II. Accuracy
Technical accuracy in all robotics, ROS 2, Gazebo, NVIDIA Isaac, Unity, and Vision-Language-Action content. All instructions must be verified through official documentation or reliable sources.

### III. Reproducibility
Every step, command, and code example must be repeatable and testable. All procedures must work when followed by users, with clear verification steps included.

### IV. Practical focus
Emphasis on real robot workflows, examples, diagrams, and hands-on practical applications rather than theoretical concepts alone.

### V. Structured presentation
Content must follow a structured format of 12 chapters with 4 modules and a weekly learning plan. Each chapter must include: explanation → example → diagram → code → practice task.

### VI. Originality and Verification
No plagiarism - all content must be original. All code must be runnable and verified. All diagrams and screenshots must include alt-text. Docusaurus-compatible Markdown formatting required for all files.

## Modules

### Module 1: ROS 2 (robot nervous system)
Fundamental concepts of Robot Operating System 2 for controlling robotic platforms.

### Module 2: Gazebo & Unity (digital twin simulation)
Simulation environments for testing and validating robotic behaviors in digital twins.

### Module 3: NVIDIA Isaac (AI perception & navigation)
Advanced AI capabilities for robot perception, navigation, and intelligent decision-making.

### Module 4: Vision-Language-Action (LLM + robotics integration)
Integration of large language models with robotic systems for advanced human-robot interaction.

## Weekly Plan

- Weeks 1–2: Intro to Physical AI
- Weeks 3–5: ROS 2 fundamentals
- Weeks 6–7: Gazebo simulation
- Weeks 8–10: NVIDIA Isaac platform
- Weeks 11–12: Humanoid robotics (walking, grasping, interaction)
- Week 13: Conversational robotics (GPT + speech + vision)

## Constraints

- Book must contain exactly 12 chapters
- Writing must be simple and easy for students
- Each chapter must include at least one picture or diagram
- Code must be explained line-by-line where needed
- Docusaurus sidebar automatically generated from folder structure
- Repository must remain deployable without errors

## Key Standards

- Every chapter must include: explanation → example → diagram → code → practice task
- All code must be runnable and verified
- All diagrams/screenshots must include alt-text
- No plagiarism; content must be original
- Docusaurus-compatible Markdown formatting for all files
- Front page must include a hero section, modules grid, and navigation
- Book must be deployable on GitHub Pages and Vercel without build errors

## Success Criteria

- Book builds successfully in Docusaurus
- Fully deploys on GitHub Pages and/or Vercel
- All chapters easy to understand for beginners
- Examples run successfully (ROS 2, Gazebo, Isaac where applicable)
- Final capstone project (Autonomous Humanoid) described clearly
- Visuals, diagrams, and code examples properly integrated

## Tools

Spec-Kit Plus, Claude Code, Docusaurus, ROS 2, Gazebo, NVIDIA Isaac, Unity.

## Governance

This Constitution supersedes all other practices. Amendments require documentation, approval, and a migration plan. All PRs/reviews must verify compliance.
Compliance reviews will be conducted bi-annually.
